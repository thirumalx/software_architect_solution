| Model                                                          | DC     | DR              | Traffic              | Data/Storage                                           | Typical use                                  |
| -------------------------------------------------------------- | ------ | --------------- | -------------------- | ------------------------------------------------------ | -------------------------------------------- |
| **1. Active–Passive (Cold/Warm DR)**                           | Active | Standby         | DC only              | Replicated                                             | Cost-effective DR                            |
| **2. Active–Passive (Hot Standby)**                            | Active | Running/standby | DC only normally     | Continuously replicated                                | Faster failover                              |
| **3. Active–Active (Load Balanced)**                           | Active | Active          | Both receive traffic | Usually independently managed/replicated               | High availability + scale                    |
| **4. Active–Active with Shared Storage**                       | Active | Active          | Both                 | Same/shared filesystem                                 | Shared file access                           |
| **5. Active–Active with Storage Replication**                  | Active | Active          | Both                 | Separate storage, synchronous/asynchronous replication | Site resilience                              |
| **6. Active–Active with Database Replication**                 | Active | Active          | Both                 | Separate DBs with replication                          | Distributed application                      |
| **7. Active–Active Multi-Primary DB**                          | Active | Active          | Both                 | Both DBs can accept writes                             | High availability, complex conflict handling |
| **8. Active–Active Read/Write Split**                          | Active | Active          | Both                 | Primary/write + replicas/read                          | Read-heavy workloads                         |
| **9. Active–Active Application / Active–Passive Database**     | Active | Active          | Both                 | One DB primary                                         | Application HA without DB multi-write        |
| **10. Active–Active Stateless Application + Centralized Data** | Active | Active          | Both                 | Central DB/storage                                     | Common enterprise pattern                    |
| **11. Active–Active with Distributed Storage**                 | Active | Active          | Both                 | Distributed filesystem/object storage                  | Large shared-file environments               |
| **12. Active–Active Multi-Site / Geo-Cluster**                 | Active | Active          | Both                 | Replicated/distributed                                 | Geographic resilience                        |
